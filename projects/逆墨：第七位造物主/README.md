# 《逆墨：第七位造物主》

> 原创连载漫画 × 动画短片 | 创作资产 V1

**故事**：午夜墨港，12岁自封英雄的林燧拳击黑甲巨骸胸口，系统却识别出他是「第七位造物主」。

## 目录

- `00_资产登记`：资产 manifest / 状态及来源
- `01_创作圣经`：剧情、世界观、风格、设定差异
- `02_角色资产`：按角色独立文件夹
- `03_场景资产`：固定地理与背景
- `04_漫画/EP01`：18 格漫画分镜及画格
- `05_视频/EP01`：12 镜头、首尾帧和每镜提示词
- `06_音频`：原始音频与声画对齐
- `07_特效与字卡`：墨点、速度线和中文叠字
- `08_审核`：角色、镜头、时间轴质量标准
- `99_早期概念稿`：综合大图，仅作参考

**重要**：文字文档已提交；已经生成的 PNG 如果 manifest 标记为 `local_only`，表示真实二进制图片尚未传入本仓库，需单独同步，不能将登记记录误认作图片已入库。

# 《逆墨》V4 原始 PNG 导入

此脚本用于把聊天附件 \`逆墨_第七位造物主_V4_独立资产包.zip\` 中两张原始 PNG 无损同步至 \`983033995/video-assets\`，包括 SHA-256 校验、禁止覆盖不同字节、只提交两张指定图片、更新 asset-manifest.json。

当前本仓库**只有同步脚本与候选元数据**；尚不包含 CH-04 和 BG02-A 的二进制 PNG。请勿在脚本成功推送前将 manifest 状态改为 \`committed\`。

先下载 ZIP，并在完成 GitHub 认证的本地终端运行：

\`\`\`bash
git clone https://github.com/983033995/video-assets.git
cd video-assets
python3 tools/import-ni-mo-v4.py "$HOME/Downloads/逆墨_第七位造物主_V4_独立资产包.zip" --dry-run
python3 tools/import-ni-mo-v4.py "$HOME/Downloads/逆墨_第七位造物主_V4_独立资产包.zip" --push
\`\`\`

成功后可在仓库这两处查看 PNG：
- \`projects/逆墨：第七位造物主/02_角色资产/CH-04_白檐/白檐_独立定妆_候选_v001.png\`
- \`projects/逆墨：第七位造物主/03_场景资产/BG-02_R7屋顶/BG02_A_空景_v001.png\`

注意：脚本不会认可生成失败的漫画拼贴；只有这两张候选图会入库。图像审核依然为 \`draft\`，不会自动改为通过。
